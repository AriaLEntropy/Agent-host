这个模块负责本机助手：在本机查找已安装的 ACP 助手和 DeepSeek Harness，用 ACP 连上它们，并把 `bus` 发来的命令与助手会话互相翻译。

它先在本机查找已经安装的助手：注册表里的 ACP 助手，以及本机的 DeepSeek Harness。没找到的不会去连。

找到之后用 ACP 连接。ACP 是助手进程的标准输入输出协议，一行一条 JSON。DeepSeek Harness 在数据里单独标成 `dsh`，启动参数是 `dsh --profile acp`，进进程之后走的仍是同一套 ACP。

连接建立后做双向翻译：手机经 `bus` 发来的命令（新建任务、续聊、审批、中断、拉取对话）翻成 ACP 调用；助手会话里的变化写回 `bus` 的任务存储，由那里生成快照和事件。
