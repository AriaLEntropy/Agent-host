这个模块对隧道提供 BotBus 协议接口：向手机交出这台电脑的快照和事件，接收手机的命令，按编号去重后交给 `connectors` 执行。

`router.ts` 处理隧道里的 `/bus` 请求：`/bus/describe` 告诉手机这是电脑端程序，`/bus/snapshot` 交出当前状态，`/bus/commands` 接收命令。产物下载和上传的地址还在，目前分别返回找不到和过大。

`store.ts` 是这台电脑的状态：有哪些助手、任务和项目。状态变化时序号加一，并生成快照或事件。

`commands.ts` 按命令编号去重。同一个编号 24 小时内再来，直接返回上次结果，不再执行。第一次到来时交给 `connectors` 去执行。

`socket.ts` 按序号把快照和之后的事件推给手机。序号已经是最新的，就只推后面的变化。
